# 考情监测系统

**状态**: 🚧 开发中 | **进度**: 60% | **最新更新**: 2026-08-17

---

## 📖 项目简介

考情监测系统是一个自动化的招考信息聚合平台，通过爬虫技术定期抓取全国各省市政府官网发布的事业单位、公务员、教师等招考公告，进行智能分类和结构化展示，为考生提供一站式信息查询服务。

### 核心功能
- ✅ **自动爬取** - 8 个重点省市网站，每天自动更新
- ✅ **智能分类** - 自动识别考试类型（事业单位/公务员/教师等）
- ✅ **多维筛选** - 按地区、类型、时间筛选
- ⏳ **实时展示** - 列表页 + 详情页，直达官方源
- ⏳ **用户反馈** - 申请新增网站、报告数据错误

### 技术栈
- **爬虫**: Node.js + Cheerio + Axios
- **数据库**: Cloudflare D1 (SQLite)
- **API**: Cloudflare Workers
- **前端**: Next.js 14 + Tailwind CSS
- **部署**: Cloudflare Pages
- **定时任务**: Cloudflare Cron Triggers

## 🚀 快速开始

### 1. 爬虫测试

```bash
cd crawlers
npm install
npm test              # 测试所有网站
node process.js       # 批量处理数据
```

### 2. 数据处理

```bash
# 生成 SQL 导入脚本
node generate-import-sql.js

# 输出文件
# - output/processed-data.json (1424 条数据)
# - output/import-data.sql (1.06 MB)
```

### 3. API 开发

```bash
cd api
npm install
npx wrangler dev      # 本地开发
npx wrangler deploy   # 部署到 Cloudflare
```

### 4. 前端开发

```bash
cd frontend
npm install
npm run dev           # 本地开发 (localhost:3000)
npm run build         # 构建生产版本
```

## 🔒 合规说明

### 数据来源
- ✅ 仅爬取政府公开发布的招考公告
- ✅ 所有数据均来自 .gov.cn 官方域名
- ✅ 保留原始来源链接

### 爬虫规范
- ✅ User-Agent 明确标识: `KaoQingBot/1.0`
- ✅ 访问频率: 每天 1-2 次
- ✅ 请求延迟: 每个网站间隔 1-2 秒
- ✅ 遵守 robots.txt
- ✅ 错误重试机制（最多 3 次，指数退避）

### 数据使用
- ✅ 仅用于信息聚合展示
- ✅ 不修改原始内容
- ✅ 用户点击跳转到官方网站
- ✅ 提供数据纠错和申请移除功能
