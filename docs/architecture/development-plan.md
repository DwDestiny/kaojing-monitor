## 技术栈确认

### 前端
- **框架**：Next.js 14 (App Router)
- **UI**：TailwindCSS + shadcn/ui
- **状态管理**：React Query (数据获取)

- **运行时**：Cloudflare Workers
- **框架**：Hono (轻量级路由)

- **爬虫**：Cheerio + node-fetch

### 数据库
- **主库**：Cloudflare D1 (SQLite)
- **缓存**：Cloudflare KV

### 工具链
- **语言**：TypeScript
- **包管理**：pnpm
- **部署**：Wrangler CLI + GitHub Actions

## 风险与应对

### 风险 1：爬虫适配难度
**描述**：政府网站格式各异，5 个网站可能不够验证通用性  
**应对**：
- 先做 2-3 个典型网站，验证架构
- 设计灵活的 Selector 配置格式
- 预留"手动编写解析器"的扩展点

### 风险 2：Cloudflare Workers 超时
**描述**：单次爬取时间过长（CPU 限制 50ms）  
**应对**：
- 拆分任务，每次只爬 1 个网站
- 使用 Durable Objects 处理长任务（付费功能）
- 或改用独立服务器运行爬虫

### 风险 3：信息提取准确率低
**描述**：正则匹配可能漏掉部分格式  
**应对**：
- 人工标注 50 条样本，迭代规则
- 允许"缺失字段"，不强制完整性
- 后期接入 LLM 提取（GPT-4o-mini）
