## 一、从 Excel 反推的真实业务模型

### 1.1 这份表是什么

这是**公考培训机构辅导员（销售/咨询岗）的"考情咨询工作台"**——他们靠这张表回答学员的每一个问题：

> "X 省今年能不能报？什么时候报名？考什么科目？进面分多少？备考时间够不够？"

最终产品不是表本身，而是**"考情咨询话术"**：学员问 → 查表 → 拿数据背书 → 促成报名。

### 1.2 他们收集的 20 组维度（全库实测）

| 组 | 维度 | 覆盖表 | 填充度 |
|---|---|---|---|
| 身份 | 考试/项目名称、年份 | 全部 | 🔴 必填 |
| 公告 | 发布时间、公告网址 | 全部 | 🔴 必填 |
| 规模 | 招录/招考人数 | 全部 | 🟡 格式极乱（"38119"/"3.81w"/"未知"混用） |
| 报名 | 报名时间、缴费时间 | 公考/选调/事考 | 🔴 精确到时分 |
| 资料 | 职位表/报考指南/专业目录 | 公考 | 🔵 链接列 |
| 热度 | 报考人数/报名热度 | 公考对比表 | 🟠 含"只公布区间" |
| 笔试 | 笔试时间、笔试科目、笔试具体时间 | 全部 | 🔴 科目列常 200-400 字长文本 |
| 出分 | 成绩查询时间、是否告知排名 | 全部 | 🟡 **"是否告知排名"是咨询关键** |
| 面试 | 面试时间、面试形式、面试名单发布、面试比例 | 全部 | 🟠 "未知"泛滥（录入时点未到） |
| 后续 | 体测时间、资格审查时间 | 公考 | 🟡 |
| 政策 | 19 问差异化（应届/学历/户籍/分卷…） | 差异化表 | 🔴 话术核心 |
| 区域 | 大区/省份/市县 | 全部 | 🔴 |
| 计算 | 面试间隔天数、备考周期、招录同比 | 对比表 | 🔵 人工手算 |
| 备注 | 自由文本（递补/无面试/特殊说明） | 多数 | ⚪ |

### 1.3 他们怎么用（使用模式）

1. **目录导航**：按考试类型分区，👆=置顶主推表（26公考）
2. **按类型×年份分表**：每年复制上年表改年份 → 历年可比
3. **滚动补录**：公告期填前半段，出分/面试后再回填后半段
4. **表格即话术库**：政策问答、笔试解读、"仅供参考"笔记、答疑话术直接照表答复学员
5. **暗语系统**："——"不适用、"未知"未查到、"无"明确没有、"向右看"参照右列、"🚫"易错点
6. **链接化办公**：公告/职位表/PDF 全部超链接（微盘共享，多人协作）
7. **对比分析背书**：人工维护近 5 年时间线/招录对比/面试周期，用于"去年 X 月出公告、备考 37 天"话术

### 1.4 表格的 11 个痛点（= 网站的 11 个机会）

| # | 痛点 | 网站解法 |
|---|---|---|
| 1 | 日期格式严重不统一（序列号/中文长串/混合） | 系统归一化存储 YYYY-MM-DD + 时间戳 |
| 2 | 缺失值 4 种写法（未知/——/无/空）语义混乱 | 结构化状态字段（pending/na/none/known） |
| 3 | 人数格式乱（数字/万/约/未知） | 数值化 + 原始值保留 |
| 4 | 目录与 sheet 脱节（漏 26 系列、多 23银行） | 自动导航、系统生成 |
| 5 | 跨表重复（26选调 vs 历年选调） | 单库 + 去重 + 唯一键 |
| 6 | 无进度状态列 | 自动推导进度（已发布/报名中/已出分/已面试） |
| 7 | 规模失控（25事考 13175 行人工录） | 爬虫自动采集 + 人工校对 |
| 8 | 早期模板列漂移（23 vs 24-26 对不齐） | 统一 schema + 版本迁移 |
| 9 | 科目/备注列膨胀（200-400 字） | 结构化子表 + 长文本分离 |
| 10 | 面试阶段"未知"率高 | 自动追踪补录 + 提醒 |
| 11 | 对比表人工手算 | 自动计算（间隔天数/同比/备考周期） |

## 二、产品定位升级

```
v1（现状）：招考公告聚合展示站          →    v2（目标）：考情咨询工作台
  · 面向：考生/访客                         · 面向：辅导员（主）+ 考生（次）
  · 数据：139 条公告，字段残缺               · 数据：全维度考情（对齐表格 20 组维度）
  · 能力：看列表、筛地区、跳原文              · 能力：查考情、算周期、看对比、出话术
  · 形态：公开信息页                        · 形态：工作台 + 咨询助手
```

**核心转变**：从"被动展示爬到的公告" → 到"主动支撑咨询决策的考情知识库"。

## 三、数据模型规划（对齐表格维度）

### 3.1 核心实体

```
exam_types（考试类型）: 公考/选调/事业单位/三支一扶/教师/招警/银行/军队文职/国央企/财会/考研/其他
exams（考试项目）: 按 类型×年份×地区 组织，如"26国考""26山东事业单位"
announcements（公告）: 现有表 + 扩展字段
exam_timeline（考试时间线）: 公告/报名/缴费/准考证/笔试/出分/面试/体测/资审 各节点
exam_policies（政策问答）: 19 问差异化（应届/学历/户籍/分卷）
exam_compare（对比数据）: 历年招录/时间线/面试周期
materials（资料链接）: 职位表/报考指南/专业目录/常见问题/PDF
notes（备注/话术）: 自由文本 + 暗语标记
```

### 3.2 announcements 表扩展（对齐维度）

```sql
-- 现有字段保持（title/url/region/recruit_count/exam_date/exam_type...）
-- 新增对齐字段：
exam_category        TEXT    -- 考试类型（公考/选调/事业...）vs 现有 examType
exam_stage           TEXT    -- 进度：announced/registering/paid/permit/examined/scored/interviewed/done
announce_published_at TEXT   -- 公告发布时间（精确时分）
exam_score_rank      BOOLEAN -- 是否告知笔试成绩排名
exam_score_time      TEXT    -- 笔试出成绩时间
interview_list_at    TEXT    -- 面试名单发布时间
interview_ratio      TEXT    -- 面试比例
physical_test_at     TEXT    -- 体测时间
qualification_review_at TEXT -- 资格审查时间
is_known             TEXT    -- 缺失语义：known/unknown/na/none
raw_source           TEXT    -- 原始表述（人数"3.81w"等保留原值）
```

### 3.3 缺失值语义统一

| 表格写法 | 系统状态 | 含义 |
|---|---|---|
| （空） | `unknown` | 未采集到 |
| "未知" | `unknown` | 未采集到 |
| "——" | `na` | 不适用（如无面试） |
| "无" | `none` | 明确没有 |
| 正常值 | `known` | 已确认 |

前端按状态渲染：`unknown`=灰"待确认"、`na`=横杠、`none`=文字"无"、`known`=正常值。

## 四、功能规划

### 4.1 考情总览（升级现有首页）

- 顶部统计卡：总考试数、今年新增、待报名、近期笔试（**真实数据**，去掉 mock）
- 考试类型 Tab：公考 / 选调 / 事业单位 / 三支一扶 / 教师 / 招警 / 银行 / 专项
- 多维筛选：类型 × 地区 × 年份 × 进度 × 科目（**科目从数据派生**）
- 列表卡片：名称、地区、进度徽标（报名中 🔴/已出分/已面试）、关键时间

### 4.2 考试详情页（新增，核心页）

按考试项目聚合，一条记录呈现全生命周期：

```
26广东事业单位
├─ 基本信息：类型/地区/年份/招录人数/公告链接
├─ 时间线（自动渲染，缺节点灰置）:
│   公告 08-12 → 报名 08-18~08-22 → 缴费 → 准考证 → 笔试 09-15 → 出分 → 面试
├─ 笔试科目（结构化展示，不堆长文本）
├─ 政策问答（该地区 19 问差异化，可折叠）
├─ 面试信息：形式/比例/名单
├─ 对比卡片：近 3 年公告时间/笔试时间/备考周期/招录同比
└─ 备注/话术（辅导员内部可见）
```

### 4.3 咨询助手（新增，核心价值）

基于考情知识库 + LLM 检索，辅导员可直接问：

> "广东事业单位备考时间多少天？" → 自动查时间线算间隔 → "去年 8月12日出公告、9月15日笔试，备考 34 天"

- 数据全部来自结构化库（**不依赖 LLM 幻觉**，LLM 只做检索+组织回答）
- 回答附数据来源（哪年哪省哪条记录）
- 支持话术导出（复制一段带数据背书的咨询回复）

### 4.4 政策差异库（新增）

- 19 问差异化表格化（对齐 Excel 的差异化问题更新表）
- 按 省份×问题 检索
- 结构化存储（应届/学历/户籍/分卷 各维度），支持筛选

### 4.5 对比分析（新增）

- 省考招录对比：省份 × 近3年（公告时间/笔试时间/备考周期/招录人数/同比）
- 面试周期对比：自动计算"出成绩 → 面试"间隔天数
- 全部**自动计算**，消灭人工手算

### 4.6 数据维护后台（新增，辅导员用）

- 补录缺失字段（公告/报名/笔试/面试分阶段补录）
- 表格数据批量导入（Excel → 系统，迁移历史 6 万条）
- 标记进度、维护政策问答、维护资料链接
- 爬虫自动采集 + 人工校对双通道
