用户要求先调研"从文章判断类型+提取信息"任务的业界可靠方案，再动手。三轮搜索结论：

### 结构化输出可靠性谱系（业界共识）
Prompt engineering（最不可靠）→ JSON mode（合法 JSON，不保证 schema）→ Function calling（schema 约束）→ Structured Outputs/约束解码（token 级强制，最可靠）
核心规则：AI 输出被代码消费时 MUST 用结构化输出，纯提示词是原型做法不可上生产

### Cloudflare Workers AI JSON Mode（官方文档确认）
- 支持 response_format: {type:"json_schema", json_schema:{...}}，兼容 OpenAI
- 支持列表不含 llama-3.2-3b-instruct（本项目当前用的）← 关键差距！
- 支持模型：llama-3.1-8b-instruct(-fast)、llama-3.3-70b-fp8-fast、llama-3-8b、llama-3.2-11b-vision、hermes-2-pro-mistral-7b、deepseek-r1-distill-qwen-32b
- JSON Mode 也不保证 100% schema 合规，极端返回错误需处理

### 中文模型选型（社区实测）
- 中文优先 Qwen/Gemma 系列；llama-3.1-8b 中文输出不稳定
- gemma-3-12b-it 中文指令遵循明显优于 llama-3.1-8b
- 分类小任务：granite-4.0-h-micro / llama-3.2-3b 够用；提取/结构化：llama-3.1-8b（JSON discipline 好）
- 中文+工具调用：GLM-4.7 Flash；中文长文提取：Qwen3-30B-A3B；高质量：llama-3.3-70b（≈GPT-4o-mini 中文）

### 分类任务最佳实践（Halterman & Keith 2025 / Chae & Davidson 2025）
- Codebook 设计：Label+Definition+Clarification+Negative clarification+Examples
- 类别少（3-6）+ 留残差类别；few-shot 不稳定需对比 zero-shot
- 微调小模型（~100 条标注）可匹配 GPT-4o zero-shot；置信度阈值+低置信人工兜底
- 规则前置是业界认可做法（本项目纯规则三级过滤方向正确）
